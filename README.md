## 📝 Notes & Tips

- Always plan your **widget tree** before building a UI.  
- Use **Scaffold** as a base for every screen.  
- Combine **Row**, **Column**, and **Stack** for flexible layouts.  
- Pay attention to **alignment, padding, and spacing**—it makes your UI clean and professional.  
- Document experiments and results in notebooks; it’s a lifesaver when reviewing.  
- Start small, try different approaches, and iterate gradually.
